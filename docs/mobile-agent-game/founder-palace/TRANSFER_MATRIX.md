# Transfer matrix

This matrix separates public methods, branded expressions, and the original Founder Palace implementation. Citations map to `RESEARCH_REPORT.md`.

| Source pattern | Decision | Original implementation | Guardrail |
|---|---|---|---|
| Method of loci | ADAPT | Bind one compact company model to an existing settlement landmark | Treat as a recall aid only; always offer list/text equivalent |
| Hint-free retrieval + feedback | ADOPT | Explain from memory, record confidence, reveal evidence/contrast, repair | Wrong recall never mutates company truth |
| Distributed practice | ADAPT | Schedule by desired horizon, difficulty, calibration and application state | No universal magic interval; no streak punishment |
| Prepared virtual memory palace | REJECT | Existing Hermes3D semantic settlement | No copied rooms, routes, art, objects, terminology, or trade dress |
| Champion-led bite-sized lessons | ADAPT | 5–10 minute provenance-bearing coach interaction | No guru authority; recommendation and uncertainty labels mandatory |
| Memory test uplift marketing | REJECT | Baseline calibration for product learning only | No broad cognition, founder-performance, revenue, or medical claim |
| Gamified XP/streak progression | REJECT | Optional milestones for verified knowledge, scenario, application, reflection | No loss aversion, shame, artificial scarcity, or retention manipulation |
| Relational/higher-order encoding | ADAPT | Knowledge hierarchy and explicit model/tradeoff links | Do not reproduce iCanStudy/HUDLE techniques or curriculum |
| Ultralearning directness/drills | ADAPT | Every skill touches a live founder task; isolate weak subskills only when needed | Do not package a branded Ultralearning mini-course |
| Identity and systems | ADAPT | Founder intent/identity connects to objective, system, and smallest approved action | Do not copy Four Laws names, diagrams, lesson text, or streak mechanics |
| Deep-work protection | ADAPT | One focus quest; batch shallow notifications; explicit shutdown/resume | Never trap the user or suppress safety-critical alerts |
| Goal setting | ADAPT | Objective + guardrails + outcomes + leading indicators + experiments | Revenue/profit default is editable; never silently optimize one objective |
| Workplace coaching | ADAPT | Questions, recommendations, commitments and outcome review | Coach cannot claim causal authority or act without approval |
| Store pricing/subscription | REJECT | Commercial model out of scope | No copied price, trial, bundle, urgency, or renewal language |

## Acceptance test

A reviewer should be able to remove every external brand name from the product UI without changing the engine. If a lesson, palace scene, metric, price, or interaction remains recognizably dependent on another product’s expression, reject and redesign it.
